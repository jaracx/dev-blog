# Dev & Support Log (Personal Blog & CRUD)

Un registro técnico personal y panel de notas/procedimientos desarrollado con Node.js, Express y Frontend nativo.

## Stack Tecnológico
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla).
- **Backend:** Node.js, Express, Dotenv.
- **Servidor & Despliegue:** Nginx (Reverse Proxy), PM2, UFW Firewall en Azure VM (Ubuntu 24.04 LTS).

## Instalación y Uso Local
1. Clonar el repositorio y entrar a backend:
   git clone https://github.com/TU_USUARIO/dev-blog.git
   cd dev-blog/backend
2. Instalar dependencias:
   npm install
3. Configurar variables de entorno:
   Copiar .env.example a .env y definir las variables requeridas
4. Iniciar la aplicación:
   npm start
